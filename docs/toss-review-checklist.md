# 토스페이먼츠 가맹 심사 체크리스트 (TOMO)

기준: 토스페이먼츠 가맹점 가이드·카드사 심사 미비 사항 가이드(2026-09 확인). 사이트 쪽은 코드로 갖췄고, **굵은 항목은 사용자가 직접 해야 하는 것**.

## 1. 사이트에 갖춰진 것 (코드 완료)

| 심사 항목 | 위치 | 상태 |
|---|---|---|
| 하단 사업자 정보: 상호·대표자·사업자등록번호·통신판매업 신고번호·주소·전화·이메일·호스팅 | 전 페이지 푸터 | env 값만 채우면 표시 (비면 "준비 중") |
| 이용약관 | `/terms` | 중개(국내)·통신판매(구매대행)·에스크로 3역할 반영 |
| 개인정보처리방침 | `/privacy` | 실제 처리 현황(Supabase·Vercel·토스·번역·배송사) 반영 |
| 취소·환불 정책 | `/refund` | 구매대행/국내 에스크로/여행 직거래 별 조건, 반품 주소·비용 |
| 상품 상세에 배송 업체·기간, 취소, 반품 방법·기한·주소·비용 | 상품 상세·외부 상품 상세 `PolicyNote` | 완료 |
| 결제 전 약관·개인정보·환불 동의 (필수 체크) | 주문서 | 완료 |
| CS 전화·이메일·운영시간 노출 | 고객센터 `/help`, 푸터 | env 값 필요 |
| 판매 상품 1개 이상 노출, 이미지·가격·설명 | 홈·상세 | 데모 상품 있음 |
| HTTPS | Vercel | 완료 |
| 카드 결제창 연동 | 토스 결제창 v2, 승인 라우트 | 테스트 키로 E2E 검증 완료 |

## 2. 사용자가 채워야 하는 값 (Vercel 환경변수 → 재배포)

사업자등록증과 **글자 하나까지 동일**하게. 다르면 심사 반려 1순위.

```
NEXT_PUBLIC_COMPANY_NAME=            상호 (예: 주식회사 토모)
NEXT_PUBLIC_COMPANY_CEO=             대표자명
NEXT_PUBLIC_COMPANY_BIZ_NO=          사업자등록번호 000-00-00000
NEXT_PUBLIC_COMPANY_MAIL_ORDER_NO=   통신판매업 신고번호 (예: 2026-서울강남-0000)
NEXT_PUBLIC_COMPANY_ADDRESS=         사업장 주소 (등록증과 동일)
NEXT_PUBLIC_COMPANY_PHONE=           고객센터 전화 (실제 받는 번호)
NEXT_PUBLIC_COMPANY_EMAIL=           고객센터 이메일
NEXT_PUBLIC_COMPANY_HOURS=           운영시간 (예: 평일 10:00–18:00, 주말·공휴일 휴무)
NEXT_PUBLIC_COMPANY_PRIVACY_OFFICER= 개인정보보호책임자 (이름 · 이메일)
NEXT_PUBLIC_COMPANY_RETURN_ADDRESS=  반품(센터) 주소
```

Vercel 대시보드 → Project → Settings → Environment Variables → Production에 추가 → Redeploy.

## 3. 서류·절차 (사용자)

1. **사업자등록증** — 업태/종목에 "전자상거래업" 또는 "통신판매업"이 있으면 유리. 없으면 홈택스에서 종목 추가(무료, 즉시).
2. **통신판매업 신고** — 관할 구청 또는 토스페이먼츠 "통신판매업 바로신청"(구매안전서비스 이용확인증 발급부터 신고까지 무료). 신고번호가 나오면 env에 넣기.
3. **토스페이먼츠 가입 신청** — tosspayments.com → 전자결제 신청서. 업종은 "전자상거래 > 중고거래/구매대행", 서비스 유형 "플랫폼(마켓플레이스)" 여부를 사실대로. 판매자 정산이 있는 마켓플레이스라 **지급대행 서비스**도 함께 문의.
4. 3영업일 내 계약 담당자 메일 → 구비서류 제출: 사업자등록증, 대표자 신분증 사본, 통장 사본(정산 계좌), 통신판매업 신고증, 사이트 URL.
5. **심사용 테스트 계정** — 심사 담당자가 로그인해 결제 흐름을 봅니다. 이메일 회원가입으로 계정 하나 만들어 ID/PW를 신청서 비고에 적어 주세요. (비회원 결제는 TOMO 정책상 없음 → 비고에 "회원 결제만 지원, 테스트 계정 제공"이라고 명시)
6. 심사 통과 → 상점관리자에서 **라이브 키** 발급 → Vercel `TOSS_CLIENT_KEY`/`TOSS_SECRET_KEY` 교체 → 재배포 → 1,000원 실결제 테스트 후 취소.
7. 일본 구매자 카드를 받으려면 상점관리자에서 **해외카드 결제** 신청(별도 심사). 카카오페이·네이버페이도 각각 계약.

## 4. 심사 전 마지막 점검

- [ ] 푸터에 "준비 중"이 하나도 안 남았는지 (홈 맨 아래 확인)
- [ ] `/terms` `/privacy` `/refund`에 회사명·연락처가 채워졌는지
- [ ] 고객센터 전화가 실제로 연결되는지 (심사 중 전화 확인 사례 있음)
- [ ] 상품 상세에 "배송·취소·환불 안내" 박스가 보이는지
- [ ] 주문서에서 동의 체크 없이 결제가 막히는지
- [ ] 약관 내용 법률 검토 (초안은 TOMO 운영 방식 기준으로 작성됨 — 실제 센터 주소·정산 조건과 다르면 수정)
- [ ] 커스텀 도메인 (선택이지만 `vercel.app` 서브도메인보다 신뢰도 ↑, 심사 지연 방지)
