# 07 배포 후 화면 검수 (읽기 전용)

검수일 2026-11-26. 대상 https://tomo.airship.click (4760dbe). 데스크톱 1440x900, 모바일 390x844, ko·ja. 캡처는 `docs/aaa/shots/after-*.png`. 언어는 화면의 KR/JP 버튼으로 바꿨고 끝에 KR로 되돌렸다. 주문·결제·글쓰기·신고는 하지 않았다.

## 한계 (먼저 읽기)
- 이 브라우저는 로그인 상태다. 계정은 거주국 KR(서울 강남구)이다. 그래서 `/login` 화면과 비로그인 화면은 **확인 못 함**이다. 마이페이지는 로그인 상태로 봤다.
- 일본어 화면의 가격이 원화로 나오는 것이 언어 때문인지 계정 거주국(KR) 때문인지 구분하지 못했다. 거주국이 JP인 계정이나 비로그인으로 다시 봐야 한다.
- 콘솔 오류는 이 도구로 읽을 수 없어 **확인 못 함**이다.
- 판매 폼(`/sell`)은 이번에 열지 않았다. 신고 제출은 하지 않았다.
- 속도는 이동 후 DOM 로드 시간 1회 측정(캐시 영향 가능): 홈 0.6~1.2초, 검색 0.4~0.9초, 상세 0.5~0.6초(모바일)·3.7초(데스크톱 첫 방문), 정적 화면 0.15초.
