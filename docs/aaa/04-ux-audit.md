# TOMO 화면·UX 검수 (읽기 전용)

검수일 2026-11-23. 대상 tomo.airship.click. 데스크톱 1440, 모바일 390. 캡처는 `docs/aaa/shots/`. 로그인·주문·결제·글쓰기는 하지 않았다.

## 한계 (먼저 읽기)
- 이 브라우저는 이미 로그인된 상태였다. `/mypage`, `/sell`이 로그인 요구 없이 열렸다. 그래서 **로그아웃 로그인 화면과 「판매하기 → 로그인 요구」 화면은 못 봤다** (`tomo-login-*`는 로그인된 마이페이지, `tomo-sell-*`는 로그인된 등록 폼).
- 국내 상품 목록이 비어 있어 **국내 상품 상세는 볼 수 없었다** (`tomo-local-*`).
- 모바일은 tomo만 캡처했다. 기준 사이트는 데스크톱만 봤다. 번개장터는 JP 지역 접속이라 globalbunjang.com/jp 화면으로 넘어갔다 (한국 m.bunjang 화면 아님).
- 체감 속도는 이동 후 DOM 로드까지 시간이다(이 PC 기준 1회 측정). 검색 결과 약 5.8초, 해외상품 상세 약 5.0초, 홈 약 3.0초, 정적 화면 약 2.9초(대기 2.5초 포함).

| 「일본에서 지금 인기」 가로 줄 첫 카드가 좌측 정렬선(163px)보다 16px 왼쪽(147px)에서 시작해 잘려 보인다 | 키라팝·에어쉽은 카드 줄이 컨테이너 선과 맞는다 | 가로 스크롤 줄의 시작 패딩을 컨테이너와 맞춘다 |

| 홈이 해외직구 상품 중심이라 「한일 중고거래」 정체성이 약하다. 국내 탭은 비어 있다 | 메루카리는 자기 마켓 상품으로 화면을 채운다 | 국내 상품이 없을 때는 홈에서 「내 동네」 탭 노출을 줄이거나 채울 방법을 정한다 |
| 모바일: 하단 탭바 없음. 상단 메뉴(홈·여행 직거래…)가 가로 스크롤이라 오른쪽이 잘린다. 헤더 아이콘 5개가 작다. 떠 있는 「문의」 버튼이 콘텐츠 위에 걸린다 | 모바일 앱형 사이트는 하단 탭(홈·검색·판매·채팅·마이)을 쓴다 | 모바일 하단 탭바를 만들고 상단 가로 메뉴는 정리한다. 문의 버튼은 아이콘만 남기거나 스크롤 중 숨긴다 |
| **JP 화면에서 가격이 「9,720원〜」「38,691원」으로 원화로 나온다**(`tomo-home-jp-d`, `tomo-search-jp-d`). 상품 제목도 한국어 번역 줄과 일본어 원문 줄이 같이 나온다(JP 홈) | 메루카리·에어쉽 JA 화면은 ¥ 표기 | JP UI는 엔화 표기로 바꾸고, 한국어 번역 제목은 JP에서 숨긴다. 시급 |

### 2. 검색 결과 `/global?q=포켓몬` (`tomo-search-d`, `tomo-search-m`, `tomo-search-jp-d`)
| 문제 | 기준 사이트는 어떻게 하나 | 고칠 방향 |
|---|---|---|
| 결과 건수가 없다. 정렬이 없다. 필터는 「필터」 버튼 하나에 숨어 있다 | 번개장터는 「182275건」, 정렬, 필터 칩 4개를 바로 보여 준다. 메루카리는 좌측 필터 13종 + 정렬 5종 + 연관 칩 | 건수·정렬(추천/가격/최신)을 목록 위에 둔다. 가격·상태·마켓 칩을 바로 노출 |
| 카드 한 장에 한국어 번역 제목과 일본어 원문 제목이 같이 나와 높이가 커지고, 둘 다 말줄임(…)된다 | 메루카리는 제목 한 줄 | 번역 제목만 보이고 원문은 상세에서 본다. 호버 시 원문 |
| 카드에 상태·좋아요·배송비 부담·판매중/품절 정보가 없다. 가격만 있다 | 메루카리 카드: 가격 배지, 하트, 신규 번개 표식. 번개장터: 할인 배지, 하트 | 「배송비 포함」·「좋아요 수」·「품절」을 카드에 표시. 찜 하트 추가 |
| 카드 가격이 원화 한 줄뿐이다(엔화 원가 없음, 아래 상세에는 ¥2,100이 작게 있음) | 에어쉽은 「약 ₩13,300」 + 「¥」 병기 | 카드에도 ¥ 원가를 작게 병기 |
| 첫 결과가 5.8초 뒤에 나왔고 로딩 표시는 확인하지 못했다. 번역 안내(「번역해서 찾았어요: ポケモン」)는 작고 연해서 눈에 안 띈다 | 메루카리 검색 약 5.1초(비슷). 번개장터 약 2.8초 | 스켈레톤 카드를 먼저 보여 준다. 검색어 번역은 칩으로 바꿔 누르면 원문 검색으로 전환 |
| 일부 이미지에 판매자 사진 속 글씨·검은 띠가 그대로 나온다(상품 사진 품질은 통제 불가) | 메루카리도 같다 | 정사각 크롭 시 중앙 정렬 유지. 개선 우선순위 낮음 |
| 모바일: 2열 카드는 보기 좋다. 필터 버튼·마켓 탭 터치 영역은 충분. 문의 버튼이 카드를 가린다 | — | 문의 버튼 위치 조정 |

| 체감 속도 | 검색·상세가 5초 안팎. 이미지 120여 장을 한 번에 불러온다(`imgs:122`) | 번개장터 검색 약 2.8초 | 이미지 지연 로딩, 첫 화면 이미지 수 제한 |

## 시각·UX 개선 TOP 12 (영향 큰 순)
1. JP 화면 가격을 엔화로 바꾸고 한국어 제목 줄을 숨긴다 (현재 「9,720원〜」).
2. 모바일 하단 탭바(홈·검색·판매·채팅·마이)를 만들고 떠 있는 「문의」 버튼이 콘텐츠를 가리지 않게 한다.
3. 검색 결과 위에 건수·정렬·가격/상태 필터 칩을 노출한다.
4. 검색 카드를 한 줄 제목(번역만) + ¥ 원가 병기 + 배송비 포함 + 찜 하트로 바꾼다.
5. 상세 가격 영역에 예상 총액(국제배송비 범위 포함)을 보이고 「현지 유통비」 같은 용어를 쉬운 말로 바꾼다.
6. 상세 첫 화면에 판매자 정보·상태·발송지를 둔다 (신뢰 정보 위치).
7. 홈 첫 화면에 상품이 보이도록 히어로 높이를 줄이고 중복 검색창을 없앤다.
8. 국내 탭이 비어 있을 때 대체 콘텐츠를 보여 주고 빈 화면 문구를 개선한다.
9. 검색·상세 로딩을 스켈레톤으로 바꾸고 이미지 지연 로딩으로 5초대 체감 속도를 줄인다.
10. 카테고리 페이지에 대표 사진과 상품 수를 넣고 해외/국내 이중 버튼을 정리한다.
11. 브랜드 색 1개와 보조 텍스트 대비를 정리해 카드·버튼 위계를 만든다.
12. 판매 폼에 사진 드래그 영역과 가격 단위를 넣고, 고객센터에 FAQ 목록을 추가한다.
