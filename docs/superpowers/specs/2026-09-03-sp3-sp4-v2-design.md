# SP3·SP4 — 채팅·거래·프로필·마이페이지(SP3), 로그인·온보딩·판매 폼·어드민(SP4) v2

날짜: 2026-09-03 · 상태: 승인(사용자 사전 결정 반영, "끝까지 진행") · SP1/SP2 토큰·컴포넌트·사전 상속.

## 결정 사항
| 항목 | 결정 |
|---|---|
| 문자열 | 사용자 표면은 전부 `t(lang, key)` — 병기 폐기(One-Tongue) |
| 운영자 화면(/admin/*) | **한국어 고정** (센터 운영 인력 기준). 토큰만 v2. 사용자 표면이 아니므로 사전에 넣지 않는다 |
| 단계 타임라인 | 완료=네이비 체크, 현재=코랄딥, 대기=navy/10. 파스텔 블루 완료 표시 폐기(나라 색) |
| 폼 입력 | 흰 필 + shadow-soft + **16px 텍스트**(iOS 확대 방지), 채팅 컴포저만 아이보리(검색 입력과 같은 틴트 규칙) |
| 폼 페이지 구조 | 클라이언트 폼을 서버 페이지가 감싸 `lang`을 넘긴다 (`LoginForm`·`OnboardingForm`·`SellForm`) |

## SP3
- **채팅 목록**: h1 17/800, 행 = 56px `rounded-thumb` + 상대 닉네임 14/700 + 마지막 메시지 13 + 상품명 11 ink-soft + 시각(오늘이면 HH:mm, 아니면 M/D, 뷰어 로캘). 빈 상태 TomoSymbol + 사전.
- **채팅방**: 헤더 흰색, 44px 뒤로가기, 상품 스트립 `navy/5` 웰(썸 `rounded-thumb`, 구매자 통화 13/800, 예약/완료 뱃지). 말풍선은 발화 언어 색(블루/핑크 — 나라 색의 정당한 채팅 표면) 유지, 원문/번역 토글 사전, `lang` 속성. 컴포저 16px, 전송 44px.
- **거래**: h1 17/800, 상품 카드, 타임라인(위 규칙), 금액 카드 13px + 결제 금액 **구매자 통화 15/800 네이비**(원가 11/700), 운송장 `dl.card`, 액션·후기 사전. 후기 폼은 하트 5개 44px 라디오(코랄 채움/틴트 스트로크).
- **대행 상세**: 같은 타임라인·견적 카드 규격, `pstatus.*`/`pact.*` 사전.
- **프로필·마이페이지**: 아바타 navy/5 17/800 이니셜, h1 닉네임 17/800, `SectionHeader`로 섹션, 상품 그리드 `rounded-thumb` + 가격 13/800(비활성 ink-faint + 스크림 뱃지), 후기 하트 아이콘. 마이페이지 행: 썸 `rounded-thumb`, 제목 13, 상태 12 ink-soft, 금액 13/800. 로그아웃은 `router.push+refresh`.

## SP4
- **로그인**: 워드마크 + 태그라인(사전), 구글 버튼, 모드 탭 44px, 입력 16px, 에러 문구 전부 사전.
- **온보딩**: 워드마크 + 17/800 제목 + 서브. 나라 버튼은 파스텔 필드+딥 잉크(나라 색의 정당한 표면). **기본 나라·언어는 뷰어 언어를 따르고**, 완료 시 `tomo_lang` 쿠키를 프로필 언어로 맞춘다.
- **판매 폼**: 17/800 제목 + 서브, 라벨 13/700, 입력 16px, 파일 버튼 navy/5 필, 거래 방법 세그먼트, 카테고리 사전. `/sell?hint=`로 제목 프리필(홈 팔기 칩 연결).
- **어드민 4종**: `card`·`rounded-thumb`·navy/5 웰, 17/800 제목, 카운트 코랄딥(>0), 즉시 처리 상태는 코랄딥 뱃지. 한국어 고정.
